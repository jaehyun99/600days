# 600일 기념 모바일 웹 (최종본)

사진 7장이 이미 들어가 있는 최종본입니다.

## 파일 구성

- `index.html`
- `style.css`
- `content.js`  ← 문구/편지 수정용
- `script.js`
- `images/01.jpg ~ 07.jpg`

## 수정 방법

### 1) 편지 수정
`content.js`의 `letter.body` 부분만 바꾸면 됩니다.

### 2) 사진 문구 수정
`content.js`의 `photos` 배열 안 `caption`을 바꾸면 됩니다.

### 3) 사진 바꾸기
`images` 폴더 안 같은 파일명(`01.jpg` ~ `07.jpg`)으로 덮어쓰면 됩니다.

## GitHub 업로드
저장소 루트에 이 파일들을 그대로 올린 뒤 배포하면 됩니다.

```text
index.html
style.css
content.js
script.js
images/
```

## 메모
- 모바일 화면 기준으로 제작됨
- 사진 위 글씨가 안 묻히도록 어두운 그라데이션이 적용됨
- 갤럭시 브라우저에서도 무난하게 보이도록 구성함
